markdown-re-sip-dash

Other SIPs are referenced using SIP-X, not SIPX or SIP X.

Examples

error[markdown-re-sip-dash]: proposals must be referenced with the form `SIP-N` (not `SIPN` or `SIP N`)
  --> input.md
   |
27 | These are the backwards compatibility concerns for the SIP1234.
   |
   = info: the pattern in question: `(?i)sip[\s]*[0-9]+`

Explanation

Reports common mistakes when referencing other proposals, like omitting the hyphen (SIP1234), or replacing it with a space (SIP 1234).

For consistency, all proposals should be referenced in the same way.

Interfaces and contract names should be enclosed in backticks to avoid this error: `SIP1234`.
