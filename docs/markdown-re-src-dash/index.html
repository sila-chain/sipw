markdown-re-src-dash

Other SRCs are referenced using SRC-X, not SRCX or SRC X.

Examples

error[markdown-re-src-dash]: proposals must be referenced with the form `SRC-N` (not `SRCN` or `SRC N`)
  --> input.md
   |
27 | These are the backwards compatibility concerns for the SRC1234.
   |
   = info: the pattern in question: `(?i)src[\s]*[0-9]+`

Explanation

Reports common mistakes when referencing other proposals, like omitting the hyphen (SRC1234), or replacing it with a space (SRC 1234).

For consistency, all proposals should be referenced in the same way.

Interfaces and contract names should be enclosed in backticks to avoid this error: `SRC1234`.
