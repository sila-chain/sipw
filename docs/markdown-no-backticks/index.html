markdown-no-backticks

SIP references should not be in backticks.

Examples

error[markdown-no-backticks]: SIP references should not be in backticks
 --> input.md
  |
5 | `SIP-1234`
  |
  = info: the pattern in question: `SIP-[0-9]+`

Explanation

markdown-no-backticks ensures that authors do not circumvent SIP link requirements by putting SIP references in backticks.

While references like `SRC20` or `ISRC7777` are valid as interface names, `SIP-7777` should be rejected since it is not valid code.
