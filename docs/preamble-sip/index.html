preamble-sip

The sip header is a non-negative integer.

Examples

error[preamble-sip]: preamble header `sip` must be an unsigned integer
 --> input.md:2:5
  |
2 | sip: 1abc
  |     ^^^^^ not a non-negative integer
  |

Explanation

preamble-sip makes sure the sip front matter (or preamble) field is a non-negative integer.

Each proposal is identified with a number. The sip field holds that number.

Before an SIP Editor assigns a number, it is acceptable to leave this field as sip: <to be assigned> or omit it entirely.
